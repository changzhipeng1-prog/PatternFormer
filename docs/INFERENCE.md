# Evaluation from trained checkpoints

These commands load model weights and run inference. They do not start training.
Place the model and data files as described in [DATA.md](../DATA.md), configure the
Qwen base-model location, and run GPU commands inside your allocated environment.
All commands start from the repository root unless a `cd` is shown.

## Elliptic problems

| Problem | Generate solution fields | Refine and compute statistics | Figures |
|---|---|---|---|
| Single-parameter | `python 1D_p/test/generate_test.py` | `python 1D_p/test/compute_stats.py` | Main 2, 5 |
| Two-parameter | `python a2a4/test/generate_test.py` | `python a2a4/test/compute_stats.py` | S1, Main 5 |
| Two-dimensional | `python 2D/test/generate_test.py` | `python 2D/test/compute_stats.py` | S2–S4, Main 5 |

Generation writes `test/generated_solutions.pt`. The statistics scripts write
`test/stats.pt` and `test/stats.csv`; set `STAT_NCPU` to the CPU allocation, for example:

```bash
STAT_NCPU=4 python 1D_p/test/compute_stats.py
```

The model, data and default checkpoint paths are defined in each problem's
`code/config.py` and `test/generate_test.py`. Figure preparation is listed in
[FIGURE_RECIPES.md](FIGURE_RECIPES.md). Representative-example arrays are separate
figure inputs where specified in that guide.

## Gray–Scott deterministic evaluation

L1 denotes the larger diffusion coefficients, and L2 the smaller coefficients.

```bash
python GS/L1/code/eval_ord.py \
  --ckpt GS/L1/ckpt/epoch_60 --K 24 \
  --maxiter 8000 --early_iter 3000 \
  --out GS/L1/results/checkpoint_eval.json

python GS/L2/code/eval_ord.py \
  --ckpt GS/L2/ckpt/epoch_60 --L2 --K 24 \
  --maxiter 30000 --early_iter 0 \
  --out GS/L2/results/checkpoint_eval.json
```

These commands write per-parameter counts and coverage in JSON. `--n` selects an
initial subset for a shorter run; omitting it evaluates the test list. The GS figure
loader consumes chunked records under `results/full_chunks_L1/` or
`results/full_chunks_L2/`; it does not automatically replace those inputs with
`checkpoint_eval.json`.

## Gray–Scott noise and baseline comparisons

For smaller-diffusion noise evaluation:

```bash
(
  cd GS/L2/try
  python eval_grid.py --method noise --split test \
    --code ../code --ckpt ../ckpt/epoch_60 --L2 \
    --M 24 --passes 5 --noise 0.1 \
    --maxiter 30000 --early_iter 0 \
    --out results_grid/noise_shard_checkpoint.json
)
```

`--method random` selects classical random starts. `--method stop` uses
`--code ../baseline_stop --ckpt ../ckpt/stop_base`. For L1, use `GS/L1/try`, omit
`--L2`, and select the L1 refinement budget. `--idx_start` and `--idx_end` select
nonoverlapping slices for parallel runs. Use a separate output directory for a new
collection of shards, so existing and new populations are not concatenated accidentally.

The representative noise examples are generated by `GS/_example_gen.py`:

```bash
python GS/_example_gen.py --setup L1 --ti 576 --ckpt GS/L1/ckpt/epoch_60
python GS/_example_gen.py --setup L2 --ti 595 --ckpt GS/L2/ckpt/epoch_60 \
  --L2 --maxiter 30000 --early_iter 0
```

These write example field records for the GS gallery. The composite-figure command
is described in [FIGURE_RECIPES.md](FIGURE_RECIPES.md).

The 1D initialization evaluator selects an existing arm checkpoint through environment
variables. For example, from the repository root:

```bash
ARM_CKPT="$PWD/1D_p/ablation_pretrain/ckpt_arm2_random_s1/best_model" \
ARM_RANDOM=1 ARM_OUT="$PWD/1D_p/ablation_pretrain/gen_arm2_random.pt" \
python 1D_p/ablation_pretrain/generate_arm.py
```

Use the checkpoint belonging to the intended arm and its corresponding backbone
initialization. The figure scripts read stored training logs for training curves;
loading checkpoints for the remaining panels does not regenerate those curves.

## Evaluate a newly trained elliptic checkpoint

`CKPT_DIR` and `GEN_OUT` select the model bundle and generation output for all three
elliptic problems. `STATS_OUT` and `STATS_CSV` select the statistic outputs. For example:

```bash
mkdir -p "$RUN/eval-1d"
CKPT_DIR="$RUN/1d-nocontext/checkpoints/best_model" \
GEN_OUT="$RUN/eval-1d/generated_solutions.pt" \
python 1D_p/test/generate_test.py

GEN_OUT="$RUN/eval-1d/generated_solutions.pt" \
STATS_OUT="$RUN/eval-1d/stats.pt" STATS_CSV="$RUN/eval-1d/stats.csv" \
STAT_NCPU=4 python 1D_p/test/compute_stats.py
```

For `a2a4` and `2D`, use their scripts and selected checkpoint directories with the
same environment variable names. The figure scripts read the per-problem `test/`
paths listed in [FIGURE_RECIPES.md](FIGURE_RECIPES.md); place a chosen run's outputs
there in a separate figure working copy when assembling its panels.
