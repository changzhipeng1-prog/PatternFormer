# Historical experiment logs

Original experiment logs are in [historical/](historical/), with the original problem and experiment directory structure preserved. File sizes and SHA-256 checksums are listed in [manifest.json](historical/manifest.json).

- `1D_p/`: single-parameter elliptic experiments.
- `a2a4/`: two-parameter elliptic experiments.
- `2D/`: two-dimensional elliptic experiments.
- `GS/`: Gray–Scott data generation, training and evaluation.

Use the [experiment guide](../docs/EXPERIMENTS.md) to locate the corresponding source scripts. These logs retain their original filenames and contents, including execution paths and scheduler messages.
